`expect.size` checks the size of the response body in bytes.

```yaml
expect:
  size:
    lt: 100kb
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `size` | number or matcher | none | no | A number is an exact byte count. A matcher compares the byte count. |

Sizes in matchers are a whole number and a unit, with no space:

| Unit | Bytes |
| --- | --- |
| `b` | 1 |
| `kb` | 1024 |
| `mb` | 1024 × 1024 |
| `gb` | 1024 × 1024 × 1024 |

Units work in `gt`, `gte`, `lt`, `lte` and `between`. A bare number needs its unit: `vc check` reports V2301 with a certain fix that adds `b` (`1024` becomes `1024b`). A bare `0` is zero bytes, so `size: {ne: 0}` works.

## Examples

**An upper bound.** Catch a response that grew by accident, such as a list that lost its paging. This one calls `users#list` with `query: {limit: 2}`, which the demo answers with its first two users, 67 bytes.

```yaml title="services/sz/size.test.yaml (excerpt)"
tests:
  - id: tooBig
    call: users#list
    query: {limit: 2}
    expect:
      size:
        lt: 50b
```

```console
✕ sz.size#tooBig                                                  5ms
  error[V5101]: expect.size
   --> services/sz/size.test.yaml:7:9
    |
  7 |         lt: 50b
    |         ^^^^^^^ expected {"lt":50}, got 67
```

The expected value is shown in bytes.

**A range.**

```yaml
expect:
  size:
    between: [100b, 2kb]
```

**An exact size.** Write the byte count as a plain number. This example calls `users#delete` from the users api file in [the project these pages use](/vc-rs/reference/syntax/#the-project-these-pages-use). It sends `DELETE /users/<userId>`. The demo answers `204` when the user existed and `404` when it did not, both with no body. Users 1 and 2 are the demo's own and get a `403`, so the test creates a user to delete:

```yaml title="services/users/users.api.yaml (excerpt)"
baseUrl: ${var.usersUrl}
apis:
  - id: delete
    name: Delete a user
    method: DELETE
    path: /users/${var.userId}
    expect:
      status: [204, 404]
```

```console
$ vc call users#delete --var userId=15
404 Not Found · 3 ms · api expect passed
```

```yaml
- id: emptyBody
  before:
    - call: users#create
      keep: true
  call: users#delete
  expect:
    size: 0
```

## How it behaves

- **What is measured.** The response body in bytes. Headers are not counted.
- **Merging.** `size` is one check. A more specific level replaces it.

<Aside type="caution">
Units are only converted inside `gt`, `gte`, `lt`, `lte` and `between`. A literal such as `size: 32b`, or `eq: 32b`, is compared as the text `"32b"` and fails with `expected "32b", got 32`. Write `size: 32` for an exact size.
</Aside>

## Common errors

| Code | When |
| --- | --- |
| [V2301](/vc-rs/reference/diagnostics/v2301/) | The size is not a whole number and a unit, such as `10 kb` with a space. The help reads: write a whole number and a unit, `512b`, `4kb`, `1mb` or `2gb`. |
| [V5101](/vc-rs/reference/diagnostics/v5101/) | The body size did not match. |
