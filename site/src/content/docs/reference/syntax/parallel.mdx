`parallel` sets how many iterations of a looped step run at once. It goes next to [`repeat`](/vc-rs/reference/syntax/repeat/) or [`forEach`](/vc-rs/reference/syntax/for-each/). Without it, iterations run one after another.

The examples call `sample#createUser` from the sample api file that [`vc init`](/vc-rs/reference/cli/init/) writes:

```yaml title="services/sample/sample.api.yaml (excerpt)"
baseUrl: ${var.sampleUrl}
apis:
  - id: createUser
    name: Create a user
    method: POST
    path: /users
    vars:
      name: ${fake.person.fullName}
      email: ${fake.internet.email}
    body:
      name: ${var.name}
      email: ${var.email}
    expect:
      status: 201
    save:
      userId: ${response.body.id}
    cleanup:
      call: deleteUser
      vars:
        userId: ${response.body.id}
```

```console
$ vc call sample#createUser --var name="Ada Lovelace" --var email=ada@example.com
201 Created · 0 ms · api expect passed
{
  "email": "ada@example.com",
  "id": "6",
  "name": "Ada Lovelace"
}
```

```yaml
      - call: sample#createUser
        repeat: 3
        parallel: 3
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `parallel` | integer, at least 1 | `1` | no | The most iterations in flight at once. Needs `repeat` or `forEach` on the same step. |

Tests already run in parallel, up to `defaults.concurrency`. `parallel` is only about the iterations inside one step.

## Examples

### Overlap slow iterations

Two steps that each run `sleep 1` three times. The first runs them together:

```yaml title="services/sample/naps.test.yaml"
id: sample.naps
name: Naps

tests:
  - id: napsTogether
    name: Three naps at once
    steps:
      - command: sleep 1
        repeat: 3
        parallel: 3

  - id: napsInTurn
    name: Three naps in turn
    steps:
      - command: sleep 1
        repeat: 3
```

```console
$ vc run sample.naps
```

### Saved lists keep their order

Iterations may finish in any order, but saved values stay in iteration order:

The first test calls `echo#json`, a minimal api for this page that sends `POST /echo` with a small JSON body; the demo answers with the request it got, the body under `body`. It is in [the project these pages use](/vc-rs/reference/syntax/#the-project-these-pages-use):

```yaml title="services/echo/echo.api.yaml (excerpt)"
baseUrl: ${var.echoUrl}
apis:
  - id: json
    name: Echo a JSON body
    method: POST
    path: /echo
    vars:
      name: Ada
    body:
      name: ${var.name}
      tags: [a, b]
```

```yaml title="services/sample/parallel.test.yaml"
id: sample.parallel
name: Parallel

tests:
  - id: echoesSixNames
    name: Echoes six names, three at a time
    steps:
      - call: echo#json
        forEach: [a, b, c, d, e, f]
        parallel: 3
        vars:
          name: ${item}
        save:
          names: ${response.body.body.name}
      - call: echo#json
        expect:
          cel:
            order kept: var.names == ['a', 'b', 'c', 'd', 'e', 'f']

  - id: createsThreeAtOnce
    name: Creates three users at once
    steps:
      - call: sample#createUser
        repeat: 3
        parallel: 3
```

```console
$ vc run sample.parallel

✓ sample.parallel#createsThreeAtOnce — Creates three users at once    6ms
```

### Seed data faster

`parallel` also works on actions in lifecycle blocks. This one reads the dataset from [forEach](/vc-rs/reference/syntax/for-each/#examples):

```text title="datasets/people.csv"
email,name
ann@example.com,Ann
bob@example.com,Bob
```

```yaml
beforeAll:
  - id: team
    call: sample#createUser
    forEach: ${dataset.people}
    parallel: 2
    vars:
      email: ${item.email}
      name: ${item.name}
```

## How it behaves

- At most `parallel` iterations are in flight at once. When one finishes, the next starts.
- Saved lists are in iteration order, not in the order calls finished.
- Each iteration that succeeds registers its own cleanup.
- If an iteration fails, the step fails once the iterations in flight finish.
- `parallel` on a step without `repeat` or `forEach` is an error (`V2211`): the step has one iteration.
- `parallel: 0`, or any number below 1, is an error (`V2302`).
