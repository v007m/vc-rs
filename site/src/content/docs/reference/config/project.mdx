`project` names the project in reports. `vc init` writes the folder name.

```yaml title="vibranium.config.yaml"
project: shop-api
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `project` | text | `vibranium` | no | Free text. |

## Examples

`vc init` in a folder named `pp` writes:

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
project: pp
```

With `project: try-syntax-b`, the CTRF report says:

```json title=".vibranium/reports/36/ctrf.json"
"environment": {
  "appName": "try-syntax-b"
}
```

and the JUnit report says:

```xml title=".vibranium/reports/36/junit.xml"
<testsuites name="try-syntax-b" tests="1" failures="1" errors="0" skipped="0" time="0.141">
```

Without `project`, both say `vibranium`.

## How it behaves

- It is only a label. It does not change which files are read or which IDs tests get.
