`defaults.perHost` caps the connections open to one host at a time. Use it to stay gentle with a small server.

```yaml title="vibranium.config.yaml"
defaults:
  perHost: 2
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `defaults.perHost` | integer | `8` | no | A whole number above 0. |

## Examples

Four tests each wait 500ms on the same host, with the default concurrency of 16.

One connection at a time:

```console
$ vc run slow.par --set defaults.perHost=1
4 passed                                                     2.0s · profile default
```

Two at a time:

```console
$ vc run slow.par --set defaults.perHost=2
4 passed                                                     1.0s · profile default
```

## How it behaves

- It works with [`defaults.concurrency`](/vc-rs/reference/config/defaults-concurrency/). Tests may be ready to run, but they wait for a free connection to their host.
- Override it with `--set defaults.perHost=2`, `VIB_DEFAULTS_PER_HOST=2` or the user config.
- A number below 1 in a file is an error, `V2302`: `defaults.perHost` takes a whole number of at least 1.
