`type: oauth2Password` logs a test user in with the password grant and sends the token as `Authorization: Bearer`.

```yaml title="vibranium.config.yaml (excerpt)"
auth:
  - id: labUser
    type: oauth2Password
    tokenUrl: ${var.labUrl}/token
    clientId: ci-runner
    clientSecret: ${secret.LAB_CLIENT_SECRET}
    username: ${var.user}
    password: ${secret.LAB_PASSWORD}
    vars:
      user: ada
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `type` | `oauth2Password` | — | yes | |
| `tokenUrl` | URL template | — | yes | |
| `clientId` | text | — | yes | |
| `clientSecret` | text or template | — | no | Without it, the client is public |
| `username` | text or template | — | yes | |
| `password` | text or template | — | yes | Use `${secret.X}` |
| `scopes` | list of text | — | no | |
| `audience` | text | — | no | |
| `refreshBefore`, `refreshOn` | | `1m`, `[401]` | no | See [Token cache and refresh](/vc-rs/reference/auth/token-cache-refresh/) |
| `vars` | map | — | no | |

## Examples

The token request the server received:

```console
POST /token
authorization: Basic Y2ktcnVubmVyOmNzLTMxMzM3
grant_type=password&username=ada&password=open-sesame
```

Log in as another user for one test. Each set of vars gets its own token:

```yaml
tests:
  - id: hidesOtherUsersItems
    call: lab#whoami
    auth:
      id: labUser
      vars:
        user: bob
```

A refused login fails every call that uses it. The message names the status, never the response body:

```console
error[V5114]: credentials could not be obtained: the token endpoint for `labLocked` answered 401
```

## How it behaves

- The client goes in HTTP Basic when `clientSecret` is set, and as a `client_id` form field when it is not.
- One token per definition and set of vars, shared for the run and refreshed before it expires.
- A refused login (400, 401, 403) is kept for the run, so tests don't each retry it and lock the account.

## Common errors

- [V5114](/vc-rs/reference/diagnostics/v5114/): the token endpoint refused the login.
