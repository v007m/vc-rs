`${env.NAME}` reads an operating-system environment variable. In Vibranium, "environment" only ever means these variables; deployments are [profiles](/vc-rs/reference/config/).

```yaml
    headers:
      x-build: ${env.CI_COMMIT_SHA}
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `env.<NAME>` | text | — | yes | The name exactly as set, case and all. |

## Examples

From the shell:

```yaml title="services/tpl/env.test.yaml"
tests:
  - id: readsEnv
    call: sample#echo
    vars:
      payload:
        fromShell: ${env.DEMO_ENV}
        fromFile: ${env.DEMO_FILE}
```

With `DEMO_FILE=from-dotenv` in `.env` at the project root, `DEMO_ENV=shell vc run tpl.env` sent:

```json
{ "fromShell": "shell", "fromFile": "from-dotenv" }
```

The process environment wins over `.env`. `DEMO_ENV=shell DEMO_FILE=shell-wins vc run tpl.env` sent:

```json
{ "fromShell": "shell", "fromFile": "shell-wins" }
```

A fallback for a variable that may be unset. `${env.SURELY_UNSET_X | default('fallback')}` gave `"fallback"`.

## How it behaves

- Values are text. Use [`int`](/vc-rs/reference/pipes/int/), [`number`](/vc-rs/reference/pipes/number/) or [`bool`](/vc-rs/reference/pipes/bool/) to convert one.
- `.env` is read from the project root. Its lines fill `env.NAME` only for names the process environment does not set. Its `VIB_*` lines are settings, not env values.
- An unset name fails the action at run time with V5111, unless a `default` pipe stands in.
- A name that `.env.schema` declares as a secret cannot be read through `env`; use [`secret`](/vc-rs/reference/templates/secret/) so it stays masked.

<Aside type="caution">
`env` values are not masked. Put tokens and passwords in `.env.schema` and read them as `${secret.NAME}`.
</Aside>

## Common errors

An unset variable, at run time:

```console
✕ tpl.env#readsUnsetEnv                                           0ms
  error[V5111]: `env.SURELY_UNSET_X` is not set
     = at: call sample#echo
```

A declared secret read through `env`:

```console
error[V2107]: `${env.DEMO_TOKEN}` reads a secret that `.env.schema` declares
 --> services/tpl/e2.test.yaml:5:16
  |
5 |       payload: ${env.DEMO_TOKEN}
  |                ^^^^^^^^^^^^^^^^^ DEMO_TOKEN is a secret
  = note: a declared secret is reachable only as `${secret.X}`, so it is masked everywhere
  = help: write `${secret.DEMO_TOKEN}`
  = fix: Replace with secret.DEMO_TOKEN (certain)
```

- [V2107](/vc-rs/reference/diagnostics/v2107/): the name is a declared secret.
- [V5111](/vc-rs/reference/diagnostics/v5111/): the variable is not set at run time.
