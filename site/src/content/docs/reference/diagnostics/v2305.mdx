A template (`${...}`) or a CEL expression does not parse. The diagnostic points at the character where parsing stopped
and says what it expected there; usually a `}` or a quote is missing.

## Wrong

```yaml title="services/users/users.api.yaml"
vars:
  host: api.example.com
baseUrl: https://${var.host
apis: []
```

## Right

```yaml title="services/users/users.api.yaml"
vars:
  host: api.example.com
baseUrl: https://${var.host}
apis: []
```


## Explain it in your terminal

The same page is built into the binary, so this works anywhere, even outside a project:

```console
$ vc explain V2305
```
