`string.fromRegExp` (and a named generator's `fromRegExp`) makes text from a small, bounded part of regex syntax:
literal characters, `.`, classes such as `[A-Z0-9_]` and `[^,]`, `\d`, `\w` and `\s`, groups `(…)` and `(?:…)`,
alternatives `a|b`, and the repeats `*`, `+`, `?`, `{n}`, `{n,}` and `{n,m}` up to 256. Lookarounds, backreferences,
named groups, other escapes, and patterns that could make more than 10000 characters are not supported, so the
generator could not promise text that matches. Rewrite the pattern with the supported syntax.

## Wrong

```yaml title="services/users/users.api.yaml"
vars:
  code: ${fake.string.fromRegExp('(?=A)[A-Z]{3}')}
baseUrl: https://api.example.com
apis: []
```

## Right

```yaml title="services/users/users.api.yaml"
vars:
  code: ${fake.string.fromRegExp('A[A-Z]{2}')}
baseUrl: https://api.example.com
apis: []
```
