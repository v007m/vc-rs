An api's URL is its `baseUrl` and its `path` joined as plain text, so the two must meet at exactly one `/`. A
`baseUrl` that ends in `/` makes every path start with `//`; a `path` without its leading `/` runs into the host
(`https://api.example.comusers`). Write `baseUrl` without a trailing `/` and every `path` with a leading one.
`vc check --fix` removes the trailing `/` or adds the leading one. A `path` that is a full URL or starts with a
template (`${var.usersUrl}/users`) is left alone.

## Wrong

```yaml title="services/users/users.api.yaml"
baseUrl: https://api.example.com/
apis:
  - id: getUser
    path: users/1
```

## Right

```yaml title="services/users/users.api.yaml"
baseUrl: https://api.example.com
apis:
  - id: getUser
    path: /users/1
```
