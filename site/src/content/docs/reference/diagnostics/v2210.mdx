An action in `beforeRun` or `beforeAll` saves values, but has no `id`. Values saved there are shared under the action's
ID (`${var.member.userId}`), so without one nothing can read them.

## Wrong

```yaml wrong V2210 title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml wrong V2210 title="services/users/crud.test.yaml"
beforeAll:
  - call: users#createUser
tests:
  - id: getsUser
    call: users#getUser
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml title="services/users/crud.test.yaml"
beforeAll:
  - id: member
    call: users#createUser
tests:
  - id: getsUser
    call: users#getUser
```
