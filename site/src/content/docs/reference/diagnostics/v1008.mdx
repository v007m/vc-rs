YAML tags such as `!!str` or `!include` are not supported. Every value's type comes from the key it sits under, so a tag
is never needed; quote a value to keep it as text.

## Wrong

```yaml wrong V1008 title="services/users/users.api.yaml"
name: !!str Users
apis: []
```

## Right

```yaml title="services/users/users.api.yaml"
name: Users
apis: []
```


## Explain it in your terminal

The same page is built into the binary, so this works anywhere, even outside a project:

```console
$ vc explain V1008
```
