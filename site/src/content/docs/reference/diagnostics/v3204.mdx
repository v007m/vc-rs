YAML reads a ` #` in an unquoted value as the start of a comment, so the value was cut short: `see #212` keeps only
`see`. Quote the value to keep the `#` and what follows it.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
    skip: flaky upstream, see #212
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
    skip: 'flaky upstream, see #212'
```

## Seen in practice

This is real output from `vc`, run against the files below.

```yaml wrong title="services/users/crud.test.yaml"
id: users.crud
name: Users CRUD
tests:
  - id: listsUsers
    name: Lists users
    call: users#listUsers
    skip: flaky upstream, see #212
```
