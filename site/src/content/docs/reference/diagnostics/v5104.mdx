A request, a `poll` or a whole test ran past its time limit. A request waits for the api's `timeout`, else
`defaults.timeout`, else 30 s; a test's `timeout` covers each attempt. Raise the limit where the slow work really
needs it, rather than for the whole project.

## Wrong

```yaml title="services/reports/reports.api.yaml"
apis:
  - id: buildReport
    method: POST
    path: /reports
    timeout: 100ms
```

## Right

```yaml title="services/reports/reports.api.yaml"
apis:
  - id: buildReport
    method: POST
    path: /reports
    timeout: 20s
```
