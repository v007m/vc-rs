Hooks run inside the engine, not in Node, so a hook file can import only two things: other files in the project, by a
path starting `./` or `../` (the extension may be left off), and `vibranium:std`, which holds the helpers a hook may use
(`hmacSha256Hex`, `sha256Hex`, `base64Encode`, `base64Decode`, `urlEncode`, `urlDecode`). Packages, `node:` modules and `import()` are refused. Types from
`@vibranium/sdk` are fine with `import type`, which is removed before the hook runs. A `function:` that names a file not
ending in `.ts`, `.mts`, `.js` or `.mjs` is V2008 too.

## Wrong

```yaml wrong title="services/orders/orders.api.yaml"
beforeRequest:
  - function: ../../hooks/sign.ts#sign
apis:
  - id: listOrders
    path: /orders
```

```ts title="hooks/sign.ts"
import { createHmac } from "node:crypto";

export function sign() {
  return createHmac("sha256", "key").digest("hex");
}
```

## Right

```yaml title="services/orders/orders.api.yaml"
beforeRequest:
  - function: ../../hooks/sign.ts#sign
apis:
  - id: listOrders
    path: /orders
```

```ts title="hooks/sign.ts"
import { hmacSha256Hex } from "vibranium:std";

export function sign() {
  return hmacSha256Hex("key", "");
}
```
