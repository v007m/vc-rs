`${item}`, `${example}` and `${iteration}` exist only inside the block that makes them: `item` inside `forEach`,
`example` in a test with `examples`, and `iteration` inside `repeat`, `forEach` or a repeated test.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
    vars:
      userId: ${item.id}
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    examples:
      - id: 1
      - id: 2
    call: users#getUser
    vars:
      userId: ${example.id}
```
