A `${env.X}` reads a variable that `.env.schema` declares as a secret. A declared secret is reachable only as
`${secret.X}`, so it is masked everywhere: read through `env` it would show in reports, history and logs. Write
`${secret.X}` instead; the fix is certain.

## Wrong

```dotenv title=".env.schema"
# @defaultSensitive=true
API_TOKEN=
```

```yaml skip title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
    headers:
      authorization: Bearer ${env.API_TOKEN}
```

## Right

```dotenv title=".env.schema"
# @defaultSensitive=true
API_TOKEN=
```

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
    headers:
      authorization: Bearer ${secret.API_TOKEN}
```
