A `command:` action exited with a status other than 0, so the action failed. The command's output is attached to the
report. Commands run in the project root through `sh -c` (`cmd /C` on Windows); make a setup command succeed when the
state it sets up is already there.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml title="services/users/crud.test.yaml"
beforeAll:
  - command: mkdir build
tests:
  - id: listsUsers
    call: users#listUsers
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml title="services/users/crud.test.yaml"
beforeAll:
  - command: mkdir -p build
tests:
  - id: listsUsers
    call: users#listUsers
```
