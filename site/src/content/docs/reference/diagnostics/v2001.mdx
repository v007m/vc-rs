Two items share an ID where IDs must be unique. Each file has one ID namespace, so an api and a test in one file cannot
share an ID either, and two files cannot derive the same file ID from their paths. Rename one of them.

## Wrong

```yaml wrong V2001 title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: getUser
    path: /users/2
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: getAdmin
    path: /users/2
```
