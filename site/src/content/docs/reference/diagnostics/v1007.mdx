YAML anchors (`&name`) and aliases (`*name`) are not supported: they make a file hard to read and to edit safely. Share
values through the places that are made for it instead, such as a file's `headers`, which every api in the file gets.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
headers: &common
  accept: application/json
apis:
  - id: getUser
    path: /users/1
    headers: *common
```

## Right

```yaml title="services/users/users.api.yaml"
headers:
  accept: application/json
apis:
  - id: getUser
    path: /users/1
```
