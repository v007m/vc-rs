`vc check` reads the `http.tls` material the config writes as text, a path or inline PEM, and loads it as a run
would. Text that is not a PEM certificate, a PEM private key or a PKCS#12 bundle, an encrypted PEM key, a key that
is not the certificate's, or a bundle whose `passphrase` is wrong is this error; a run would stop on it (V5125,
V5126). A bundle with no `passphrase` is opened with an empty one. Here `key` is the key of another certificate:
give each `cert` the key it was issued with.

## Wrong

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
profiles:
  - id: dev
    default: true
http:
  tls:
    clients:
      - id: paymentsClient
        hosts: [payments.internal.example]
        cert: certs/payments-client.pem
        key: certs/orders-client.key
```

## Right

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
profiles:
  - id: dev
    default: true
http:
  tls:
    clients:
      - id: paymentsClient
        hosts: [payments.internal.example]
        cert: certs/payments-client.pem
        key: certs/payments-client.key
```
