More than one profile is marked `default: true`, so it is unclear which one a run uses when it names none. Keep the mark
on one profile.

## Wrong

```yaml wrong V3102 title="vibranium.config.yaml"
syntaxVersion: 2
profiles:
  - id: dev
    default: true
  - id: ci
    default: true
```

## Right

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
profiles:
  - id: dev
    default: true
  - id: ci
```


## Explain it in your terminal

The same page is built into the binary, so this works anywhere, even outside a project:

```console
$ vc explain V3102
```
