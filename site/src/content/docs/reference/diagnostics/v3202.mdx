`cache` keeps an action's result across runs, but this action runs for every test (in `beforeEach`, `afterEach`,
`before`, the steps or `after`), where each test is meant to get fresh data. Move the action to `beforeAll` or
`beforeRun`, or drop `cache`.

## Wrong

```yaml wrong V3202 title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml wrong V3202 title="services/users/crud.test.yaml"
beforeEach:
  - id: member
    call: users#createUser
    cache: {for: 1h}
tests:
  - id: getsUser
    call: users#getUser
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml title="services/users/crud.test.yaml"
beforeAll:
  - id: member
    call: users#createUser
    cache: {for: 1h}
tests:
  - id: getsUser
    call: users#getUser
```
