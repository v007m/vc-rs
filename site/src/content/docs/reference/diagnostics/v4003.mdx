Api files live at `services/<service>/<service>.api.yaml` and test files at `services/<service>/<area>.test.yaml`, so a
test file sits next to the apis it calls and its ID reads `<service>.<area>`. Vibranium finds a file wherever it is;
this warning only keeps projects alike. `vc rename` moves a file and updates every reference.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
```
