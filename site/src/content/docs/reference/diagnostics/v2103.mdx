A `${example.x}` names a column that no row of the test's `examples` has. Only inline rows are checked; rows from a
`$file` or a dataset are known only when the test runs.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    examples:
      - userId: 1
      - userId: 2
    call: users#getUser
    vars:
      userId: ${example.usrId}
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    examples:
      - userId: 1
      - userId: 2
    call: users#getUser
    vars:
      userId: ${example.userId}
```
