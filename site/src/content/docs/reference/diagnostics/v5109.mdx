A `function:` or `test:` action lists a name in `provides`, but did not save it when it ran. Later templates count on
the name being set, so the action fails. Either save the value in the function, or drop the name from `provides`.
Here `seedUser` returns only `userId`.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsSeededUser
    before:
      - function: hooks/seed.ts#seedUser
        provides: [userId, userEmail]
    call: users#getUser
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsSeededUser
    before:
      - function: hooks/seed.ts#seedUser
        provides: [userId]
    call: users#getUser
```
