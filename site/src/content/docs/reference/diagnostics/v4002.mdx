An api ID is camelCase, verb first, without the service in it: the file ID already supplies the service, so
`users#usersGet` says `users` twice. `vc check --fix` renames the api and updates every reference.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: usersGet
    path: /users/1
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: get
    path: /users/1
```
