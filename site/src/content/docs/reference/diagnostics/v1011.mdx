The value is nested more than 128 levels deep. Vibranium stops there so that a hostile or broken file cannot exhaust the
stack; real definitions are never this deep.

## Wrong

```yaml title="services/users/users.api.yaml"
vars:
  deep: [[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[[]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]]
apis: []
```

## Right

```yaml title="services/users/users.api.yaml"
vars:
  deep: [[1, 2], [3]]
apis: []
```
