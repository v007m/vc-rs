A `${secret.X}` reads a secret that `.env.schema` at the project root does not list. Every secret a project reads is
declared there, one `NAME=` line each, so it can be fetched before the run and masked in all output. Add the line, or
fix the name; a close match is offered as a certain fix.

## Wrong

```dotenv wrong V2106 title=".env.schema"
# @defaultSensitive=true
API_TOKEN=
```

```yaml wrong V2106 title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
    headers:
      authorization: Bearer ${secret.API_TOKN}
```

## Right

```dotenv title=".env.schema"
# @defaultSensitive=true
API_TOKEN=
```

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
    headers:
      authorization: Bearer ${secret.API_TOKEN}
```

## Seen in practice

This is real output from `vc`, run against the files below.

```dotenv wrong V2106 title=".env.schema"
# The secret names this project uses, one NAME= line each, never their values.
# Use one as ${secret.NAME}; the value comes from the environment or .env.
# Reference: https://github.com/v007m/vc-rs/blob/master/docs/design/syntax-reference.md#secrets
API_TOKEN=
```

```yaml wrong V2106 title="services/users/users.api.yaml"
id: users
name: Users
baseUrl: http://localhost:7421
apis:
  - id: listUsers
    name: List users
    path: /users
    headers:
      authorization: Bearer ${secret.API_TOKN}
```
