Tests reuse each other through `test:` steps, and here the reuse goes round in a circle, so running any of them would
never end. The diagnostic shows the whole chain; break it by removing one `test:` step.

## Wrong

```yaml wrong V2205 title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml wrong V2205 title="services/users/crud.test.yaml"
tests:
  - id: signsUp
    steps:
      - test: logsIn
  - id: logsIn
    steps:
      - call: users#getUser
      - test: signsUp
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: signsUp
    steps:
      - test: logsIn
  - id: logsIn
    steps:
      - call: users#getUser
```
