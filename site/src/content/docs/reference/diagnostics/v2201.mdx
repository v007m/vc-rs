A test needs exactly one of `call` (a single call) or `steps` (several actions in order). With neither it does nothing,
and with both it is unclear which runs.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    name: Gets a user
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    name: Gets a user
    call: users#getUser
```
