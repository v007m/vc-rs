A `headers` key is sent as the header's name, and an HTTP header name is a token: letters, digits and
`` !#$%&'*+-.^_`|~ ``, with no spaces, colons or other characters. A name outside that cannot be sent, so `vc check`
reports it before a run fails on it. This holds wherever `headers` is written: on an api, its file, a call or step,
the config's `defaults`, an auth flow's `steps` and `apply`, and the header checks in `expect`. A header name is never
rendered, so a `$\{…\}` template in a name is reported too; the value is where a template goes.

## Wrong

```yaml wrong V2310 title="services/users/users.api.yaml"
baseUrl: ${var.usersUrl}
apis:
  - id: list
    path: /users
    headers:
      "Request Id": ${var.requestId}
```

## Right

```yaml title="services/users/users.api.yaml"
baseUrl: ${var.usersUrl}
apis:
  - id: list
    path: /users
    headers:
      X-Request-Id: ${var.requestId}
```
