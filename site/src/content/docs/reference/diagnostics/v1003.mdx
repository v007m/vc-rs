`vibranium.config.yaml` must say which version of the syntax it is written in, with `syntaxVersion`. A version newer than
this Vibranium reads is refused rather than half understood; upgrade `vc` instead.

## Wrong

```yaml wrong title="vibranium.config.yaml"
syntaxVersion: 3
project: shop
profiles:
  - id: dev
    default: true
```

## Right

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
```


## Explain it in your terminal

The same page is built into the binary, so this works anywhere, even outside a project:

```console
$ vc explain V1003
```
