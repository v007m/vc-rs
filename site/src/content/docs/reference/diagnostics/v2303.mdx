A status is neither a code from 100 to 599 nor a class such as `2xx`. Write the exact code, or the class to accept any
code in it.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
    expect:
      status: 99x
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
    expect:
      status: 2xx
```
