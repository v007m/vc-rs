A test calls an api marked `deprecated: true`. The call still runs; the warning is a reminder to move to the api that
replaces it before the old one is removed.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: listLegacyUsers
    path: /legacy/users
    deprecated: true
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#listLegacyUsers
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: listLegacyUsers
    path: /legacy/users
    deprecated: true
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
```


## Explain it in your terminal
