A `function: path#export` names an export the hook file does not have. Only value exports count (`export function`,
`export const`, `export default`, `export { … }`), not `export type` or `export interface`. When one export has a close
name, the fix rewrites the name after the `#`. A file with `export * from` may export more than it shows, so its
names are not checked.

## Wrong

```yaml wrong V2005 title="services/orders/orders.api.yaml"
beforeRequest:
  - function: ../../hooks/sign.ts#sing
apis:
  - id: listOrders
    path: /orders
```

```ts wrong V2005 title="hooks/sign.ts"
export function sign() {}
```

## Right

```yaml title="services/orders/orders.api.yaml"
beforeRequest:
  - function: ../../hooks/sign.ts#sign
apis:
  - id: listOrders
    path: /orders
```

```ts title="hooks/sign.ts"
export function sign() {}
```
