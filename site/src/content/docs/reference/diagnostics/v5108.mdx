A `function:` or `test:` action saved a value that a later template uses, but the action does not list it in
`provides`. `vc check` cannot see inside such an action, so it relies on `provides` to know what the action sets;
declare every name that later templates read. Here the hook saves `userId`, which the api's path reads in place of
its default.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
    vars:
      userId: 0
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsSeededUser
    before:
      - function: hooks/seed.ts#seedUser
        provides: [userEmail]
    call: users#getUser
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
    vars:
      userId: 0
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsSeededUser
    before:
      - function: hooks/seed.ts#seedUser
        provides: [userId, userEmail]
    call: users#getUser
```
