A `${var.x}` is used, but for some profile nothing sets `x` before that spot: no call `vars`, earlier `save`, file or
config var, or profile. The diagnostic names the profiles where it is missing and the places it could be set.

## Wrong

```yaml wrong V2101 title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml wrong V2101 title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
    vars:
      userId: 1
```

## Seen in practice

This is real output from `vc`, run against the files below.

```yaml wrong V2101 title="services/users/users.api.yaml"
id: users
name: Users
baseUrl: http://localhost:7421
apis:
  - id: getUser
    name: Get a user
    path: /users/${var.userId}
```

```yaml wrong V2101 title="services/users/crud.test.yaml"
id: users.crud
name: Users CRUD
tests:
  - id: getsUser
    name: Gets a user
    call: users#getUser
```
