The auth a call needs could not be obtained: the token endpoint refused or could not be reached, a token response or
`flow` step failed, the auth type or secret provider is unknown, or a secret did not load. The message names the
cause and the endpoint's status, never a secret or a token body. Here the client secret is read from a variable the
environment does not set; declare it in `.env.schema` and use `${secret.…}`, so a missing one is reported before any
call is made.

## Wrong

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
profiles:
  - id: dev
    default: true
auth:
  - id: shopOauth
    type: oauth2ClientCredentials
    tokenUrl: http://localhost:7421/oauth/token
    clientId: tests
    clientSecret: ${env.SHOP_SECRT}
```

```yaml title="services/orders/orders.api.yaml"
auth: shopOauth
apis:
  - id: listOrders
    path: /orders
```

## Right

```dotenv title=".env.schema"
SHOP_SECRET=
```

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
profiles:
  - id: dev
    default: true
auth:
  - id: shopOauth
    type: oauth2ClientCredentials
    tokenUrl: http://localhost:7421/oauth/token
    clientId: tests
    clientSecret: ${secret.SHOP_SECRET}
```

```yaml title="services/orders/orders.api.yaml"
auth: shopOauth
apis:
  - id: listOrders
    path: /orders
```
