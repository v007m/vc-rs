The config defines no profile, or a run has no active profile. Profiles say which environment a run talks to, so a
project needs at least one, and one of them marked `default: true` for runs that name none.

## Wrong

```yaml wrong V3101 title="vibranium.config.yaml"
syntaxVersion: 2
project: shop
```

## Right

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
```


## Explain it in your terminal

