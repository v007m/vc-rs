A `$file` names a file that is not in the project. The path is relative to the file that holds the `$file`, and a
`#/pointer` after it points inside the file. When exactly one file has a close name, the fix rewrites the path.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      $file: data/usr.json
```

```json title="services/users/data/user.json"
{"name": "Ann"}
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      $file: data/user.json
```

```json title="services/users/data/user.json"
{"name": "Ann"}
```
