A definition file could not be read: it is not readable, it is not UTF-8, it is a link that leads outside the project, or
its name holds a character a path cannot (`:`, a control or a bidi character). The diagnostic points at the file's path;
fix the file or its name.

## Wrong

```yaml wrong V1012 title="services/users/users:old.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```
