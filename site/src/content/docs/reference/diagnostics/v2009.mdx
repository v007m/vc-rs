A GraphQL document may hold several operations; the server runs the one `operationName` names. So a document with
more than one operation needs `operationName`, and the name must be one the document defines; the fix for a close
misspelling is the name itself. A document with one operation needs no name. The operation it picks must be a
`query` or a `mutation`: a `subscription` keeps a connection open, which a `graphql` api does not do yet.

## Wrong

```yaml wrong V2009 title="services/catalog/catalog.api.yaml"
type: graphql
apis:
  - id: listProducts
    body:
      query: |
        query ListProducts { products { id } }
        query CountProducts { productCount }
```

## Right

```yaml title="services/catalog/catalog.api.yaml"
type: graphql
apis:
  - id: listProducts
    body:
      query: |
        query ListProducts { products { id } }
        query CountProducts { productCount }
      operationName: ListProducts
```
