A `call`, `test` or `cleanup.call` names an api or test that does not exist. Another file's items are referred to by
their full ID, `fileId#id`; the diagnostic suggests the closest ID of the right kind, same-file IDs first. The file ID and the part after `#` are measured apart: within the named file, or a file ID one typo away, only the part after `#` is compared, so `people#nah` is not a typo of `people#echo` and `peolpe#getPerson` points only at `people#getPerson`. The named file is looked up across the whole project, so from `users.crud`, `users.admin#getsUser` points at `users.admin#getsUsers`, not `users.crud#getsUser`. When nothing in the named file is close, the part after `#` is compared across every file, so `users.crud#deletesUser` points at `users.admin#deletesUser`. With several close IDs it lists them in `help:` and offers no fix.

## Wrong

```yaml wrong V2003 title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUsr
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
```

## Seen in practice

This is real output from `vc`, run against the files below.

```yaml wrong V2003 title="services/users/users.api.yaml"
id: users
name: Users
baseUrl: http://localhost:7421
apis:
  - id: listUsers
    name: List users
    path: /users
```

```yaml wrong title="services/users/crud.test.yaml"
id: users.crud
name: Users CRUD
tests:
  - id: listsUsers
    name: Lists users
    call: users#listUser
```

```console
$ vc check
error[V2003]: unknown api "users#listUser"
 --> services/users/crud.test.yaml:6:11
  |
6 |     call: users#listUser
  |           ^^^^^^^^^^^^^^ no api has this ID
  = help: did you mean `users#listUsers`?
  = fix: Replace with users#listUsers (certain)

1 error · 0 warnings · 3 files checked
$ echo $?
2
```

## Explain it in your terminal

The same page is built into the binary, so this works anywhere, even outside a project:

```console
$ vc explain V2003
```
