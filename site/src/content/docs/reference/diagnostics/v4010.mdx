A server logs and traces each operation by its name, and `operationName` picks an operation by it, so every
operation should have one. `query { … }` and the shorthand `{ … }` have none. The fix names the operation after its
api: `getProduct` becomes `query GetProduct`.

## Wrong

```yaml title="services/catalog/catalog.api.yaml"
type: graphql
apis:
  - id: getProduct
    body:
      query: '{ product(id: "p1") { id name } }'
```

## Right

```yaml title="services/catalog/catalog.api.yaml"
type: graphql
apis:
  - id: getProduct
    body:
      query: 'query GetProduct { product(id: "p1") { id name } }'
```
