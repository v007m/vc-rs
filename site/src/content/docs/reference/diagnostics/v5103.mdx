A `custom` check's function returned a failure, or threw. The report shows the message the function gave. A check
function receives the response and returns `true`, or a message that says what is wrong; here the function is given
the wrong export, one that checks orders rather than users.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: listsUsersSorted
    call: users#listUsers
    expect:
      custom:
        - function: hooks/checks.ts#ordersAreSorted
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: listsUsersSorted
    call: users#listUsers
    expect:
      custom:
        - function: hooks/checks.ts#usersAreSorted
```
