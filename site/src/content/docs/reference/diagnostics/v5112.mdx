A template reads a column (`${example.email}`, `${item.email}`) that this row of the dataset or `examples` does not
have. `vc check` reports a column that no row has (V2103); a column that only some rows lack fails those rows at run
time. Give every row the column, or a `| default(…)` in the template.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      email: ${var.email}
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: rejectsBadEmail
    examples:
      - email: no-at-sign
      - name: Ada
    call: users#createUser
    vars:
      email: ${example.email}
    expect:
      status: 400
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      email: ${var.email}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: rejectsBadEmail
    examples:
      - email: no-at-sign
      - email: ""
    call: users#createUser
    vars:
      email: ${example.email}
    expect:
      status: 400
```
