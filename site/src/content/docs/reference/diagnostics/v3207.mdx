A `test:` action runs the reused test as written: its own calls, with their own `auth`, `headers`, `query`, `body`,
`poll` and `expect` (D270). Written on the `test:` action itself, those keys never reach the reused test's calls, so
they have no effect. Remove the key, or set it in the reused test.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: makesUser
    standalone: false
    call: users#createUser
  - id: readsNewUser
    steps:
      - test: users.crud#makesUser
        headers: {x-trace: '1'}
      - call: users#getUser
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: makesUser
    standalone: false
    call: users#createUser
    headers: {x-trace: '1'}
  - id: readsNewUser
    steps:
      - test: users.crud#makesUser
      - call: users#getUser
```
