A key is written, but it does something only when another key is there too, and that key is missing:

- `parallel` on an action without `repeat` or `forEach`. It sets how many iterations run at a time, and an action that
  does not loop has one.
- An `abortOn` metric that no `thresholds` entry names, in the scenario or in a mix test. A run stops early only when a
  threshold on the metric is breached, so the run would never stop for it.
- `$remove` in a map without `$extend`. It drops paths from the object `$extend` starts from; without one, it would be
  sent as a key named `$remove`.

## Wrong

```yaml wrong V2211 title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml wrong V2211 title="services/users/crud.test.yaml"
tests:
  - id: listsUsers
    steps:
      - call: users#listUsers
        parallel: 5
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: listsUsers
    steps:
      - call: users#listUsers
        repeat: 10
        parallel: 5
```
