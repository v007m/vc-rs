A `graphql` api's response did not carry the errors its `expect.errors` asks for. A 200 with `errors` passes unless
`expect.errors` says otherwise; it takes `none`, `any`, the list of errors expected (each entry matches some error,
and each error matches some entry) or a matcher such as `{ some: { code: TIMEOUT } }`. An entry writes `message`,
`path` (dotted, like `user.secretNote`), `code` (the error's `extensions.code`) or `extensions`, each a literal or a
matcher. Here the server also reports a `TIMEOUT` error that the list leaves out.

## Wrong

```yaml title="services/accounts/accounts.api.yaml"
type: graphql
apis:
  - id: getSecretNote
    body:
      query: 'query GetSecretNote($id: ID!) { user(id: $id) { name secretNote notes } }'
      variables:
        id: "2"
```

```yaml title="services/accounts/privacy.test.yaml"
tests:
  - id: hidesSecretNote
    call: accounts#getSecretNote
    expect:
      errors:
        - code: FORBIDDEN
          path: user.secretNote
```

## Right

```yaml title="services/accounts/accounts.api.yaml"
type: graphql
apis:
  - id: getSecretNote
    body:
      query: 'query GetSecretNote($id: ID!) { user(id: $id) { name secretNote notes } }'
      variables:
        id: "2"
```

```yaml title="services/accounts/privacy.test.yaml"
tests:
  - id: hidesSecretNote
    call: accounts#getSecretNote
    expect:
      errors:
        - code: FORBIDDEN
          path: user.secretNote
        - code: TIMEOUT
```
