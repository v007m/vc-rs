A hook file that a `function:` reference reaches does not parse as an ES module. The diagnostic points at the spot the
parser stopped, with its message; `tsc --noEmit` reports the same error. Hooks are checked when the project is, so a
typo fails `vc check`, not the first request that runs the hook.

## Wrong

```yaml title="services/orders/orders.api.yaml"
beforeRequest:
  - function: ../../hooks/sign.ts#sign
apis:
  - id: listOrders
    path: /orders
```

```ts title="hooks/sign.ts"
export function sign( {
}
```

## Right

```yaml title="services/orders/orders.api.yaml"
beforeRequest:
  - function: ../../hooks/sign.ts#sign
apis:
  - id: listOrders
    path: /orders
```

```ts title="hooks/sign.ts"
export function sign() {
}
```
