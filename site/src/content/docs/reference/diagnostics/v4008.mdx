An `allowFailure` has an `until` date that has passed (dates are compared in UTC), so it no longer holds: the test
still runs, and a failure now counts as a normal failure that fails the run. This warning makes sure a forgotten
allowance is noticed; the fix removes the `allowFailure`, or move `until` later if the reason still holds.

## Wrong

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
    allowFailure:
      reason: known bug, see issue 212
      until: 2026-01-31
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: getUser
    path: /users/1
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: getsUser
    call: users#getUser
```
