A pipe or path is applied to a value of a type it cannot handle, such as `upper` on a number. It is checked where the
value's type is known: a var every profile sets to a literal of one type.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
vars:
  limit: 10
  region: eu
apis:
  - id: listUsers
    path: /users
    query:
      limit: ${var.limit | upper}
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: listsUsers
    call: users#listUsers
```

## Right

```yaml title="services/users/users.api.yaml"
vars:
  limit: 10
  region: eu
apis:
  - id: listUsers
    path: /users
    query:
      region: ${var.region | upper}
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: listsUsers
    call: users#listUsers
```
