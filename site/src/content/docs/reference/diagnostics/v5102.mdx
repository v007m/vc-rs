A `cel` check evaluated to false. Each check is named by its key, and the report shows the values the expression
read. Here `/users` answers a plain list, so there is no `response.body.users` to count.

## Wrong

```yaml wrong title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml wrong title="services/users/crud.test.yaml"
tests:
  - id: listsUsers
    call: users#listUsers
    expect:
      cel:
        returns users: response.body.users.size() > 0
```

## Right

```yaml title="services/users/users.api.yaml"
apis:
  - id: listUsers
    path: /users
```

```yaml title="services/users/crud.test.yaml"
tests:
  - id: listsUsers
    call: users#listUsers
    expect:
      cel:
        returns users: response.body.size() > 0
```

## Seen in practice

This is real output from `vc`, run against the files below.

```yaml wrong title="services/users/crud.test.yaml"
id: users.crud
name: Users CRUD
tests:
  - id: listsUsers
    name: Lists users
    call: users#listUsers
    expect:
      status: 201
  - id: countsUsers
    name: Counts users
    call: users#listUsers
    expect:
      cel:
        returns users: response.body.users.size() > 0
```
