An `auth`, profile, dataset, generator or client certificate is referred to by an ID that is not defined. Auths,
profiles and client certificates (`http.tls.clients`, named by an auth's `clientCert`) are defined in
`vibranium.config.yaml`, and a client's `profiles` must name defined profiles too; the diagnostic suggests the closest
defined ID.

## Wrong

```yaml wrong V2002 title="vibranium.config.yaml"
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
auth:
  - id: admin
    type: bearer
    token: ${secret.ADMIN_TOKEN}
```

```yaml wrong V2002 title="services/users/users.api.yaml"
auth: admn
apis:
  - id: getUser
    path: /users/1
```

## Right

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
auth:
  - id: admin
    type: bearer
    token: ${secret.ADMIN_TOKEN}
```

```yaml title="services/users/users.api.yaml"
auth: admin
apis:
  - id: getUser
    path: /users/1
```
