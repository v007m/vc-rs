An `auth`, profile, dataset or generator is referred to by an ID that is not defined. Auths and profiles are defined in
`vibranium.config.yaml`; the diagnostic suggests the closest defined ID.

## Wrong

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
auth:
  - id: admin
    type: bearer
    token: ${secret.ADMIN_TOKEN}
```

```yaml title="services/users/users.api.yaml"
auth: admn
apis:
  - id: getUser
    path: /users/1
```

## Right

```yaml title="vibranium.config.yaml"
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
auth:
  - id: admin
    type: bearer
    token: ${secret.ADMIN_TOKEN}
```

```yaml title="services/users/users.api.yaml"
auth: admin
apis:
  - id: getUser
    path: /users/1
```
