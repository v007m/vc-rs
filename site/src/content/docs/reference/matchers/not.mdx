`not` passes when the nested matcher does not.

```yaml
expect:
  body:
    match:
      body.status: {not: {in: [closed, cancelled]}}
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `not` | matcher or value | — | yes | A plain value means the value does not equal it. |

## Examples

The examples call `sample#echoOrder`, which posts a sample order to the demo service; the demo sends it back under `body`. See [Following along](/vc-rs/reference/matchers/#following-along).

### Invert a matcher



```yaml title="services/sample/not.test.yaml"
tests:
  - id: isOpen
    name: Status is not closed or cancelled
    call: sample#echoOrder
    expect:
      body:
        match:
          body.status: {not: {in: [closed, cancelled]}}
```

### A missing path passes

The nested matcher fails on a missing value, so `not` passes. Add `exists: true` when the field is required.

```yaml title="services/sample/not.test.yaml"
tests:
  - id: passesOnMissing
    name: Missing field is not 1
    call: sample#echoOrder
    expect:
      body:
        match:
          body.state: {not: {eq: 1}}
  - id: needsTheField
    name: Status is present and not closed
    call: sample#echoOrder
    expect:
      body:
        match:
          body.status: {exists: true, not: {eq: closed}}
```

```console
$ vc run sample.not#passesOnMissing sample.not#needsTheField

```

## How it behaves

- `not` inverts the result of its nested matcher, whatever it is.
- A missing value passes, because the nested matcher fails on it.
- For simple cases, [ne](/vc-rs/reference/matchers/ne/) and [notIn](/vc-rs/reference/matchers/not-in/) read better.

## Common errors

- [V1004](/vc-rs/reference/diagnostics/v1004/): a misspelled matcher next to a real one, such as `{gt: 1, gtt: 2}`, or on its own when its name has five or more letters, such as `{startWith: A}`. The help line suggests the closest name. To compare with an object that has such a key, put it under `eq:`.
- [V5101](/vc-rs/reference/diagnostics/v5101/): the check did not hold for the response. The report shows the expected and the actual value.
