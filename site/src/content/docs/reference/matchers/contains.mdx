`contains` passes when a string includes the text, or when a list includes an element equal to the argument.

```yaml
expect:
  body:
    match:
      body.tags: {contains: vip}
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `contains` | any value | — | yes | Text match is case-sensitive. List elements are compared deeply. |

## Examples

The examples call `sample#echoOrder`, which posts a sample order to the demo service; the demo sends it back under `body`. See [Following along](/vc-rs/reference/matchers/#following-along).

### A substring



```yaml title="services/sample/contains.test.yaml"
tests:
  - id: nameHasLove
    name: Name contains Love
    call: sample#echoOrder
    expect:
      body:
        match:
          body.name: {contains: Love}
```

### An object in a list

The whole element must match. A partial object does not.

```yaml title="services/sample/contains.test.yaml"
tests:
  - id: hasItemA1
    name: Items include A1 at 10
    call: sample#echoOrder
    expect:
      body:
        match:
          body.items: {contains: {sku: A1, price: 10}}
  - id: failsOnPartial
    name: Items include sku A1
    call: sample#echoOrder
    expect:
      body:
        match:
          body.items: {contains: {sku: A1}}
```


### Values from a list path

A `[*]` path collects one field from every element into a list.

```yaml title="services/sample/contains.test.yaml"
tests:
  - id: hasSkuB2
    name: Some item is B2
    call: sample#echoOrder
    expect:
      body:
        match:
          body.items[*].sku: {contains: B2}
```

```console
$ vc run sample.contains#hasSkuB2

```

## How it behaves

- On a string, the argument is a substring and the match is case-sensitive. For a case-insensitive match, use [regex](/vc-rs/reference/matchers/regex/) with `(?i)`.
- On a list, one element must deeply equal the argument.
- On anything else, such as a number or a missing value, `contains` fails.

## Common errors

- [V1004](/vc-rs/reference/diagnostics/v1004/): a misspelled matcher next to a real one, such as `{gt: 1, gtt: 2}`. The help line suggests the closest name.
- [V3207](/vc-rs/reference/diagnostics/v3207/): a warning for a misspelled matcher on its own when its name has five or more letters, such as `{startWith: A}`. It is still compared as a literal object; fix the name, or put the object under `eq:` to keep it.
- [V5101](/vc-rs/reference/diagnostics/v5101/): the check did not hold for the response. The report shows the expected and the actual value.
