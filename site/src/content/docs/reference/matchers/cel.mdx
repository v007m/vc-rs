`cel` holds named expressions in CEL, the Common Expression Language. Each must evaluate to `true`.

```yaml
expect:
  cel:
    twoUsers: size(response.body) == 2
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `cel.<label>` | CEL expression | — | no | The label names the check in the report. It can contain spaces. |

## Examples

The examples call `sample#listUsers` and `sample#echoOrder`. See [Following along](/vc-rs/reference/matchers/#following-along).

### Count and inspect a list

Read the body as `response.body`.

```yaml title="services/sample/cel.test.yaml"
tests:
  - id: twoNamedUsers
    name: Two users, all named
    call: sample#listUsers
    expect:
      cel:
        twoUsers: size(response.body) == 2
        every user has a name: response.body.all(u, u.name != "")
```

```console
$ vc run sample.cel#twoNamedUsers
plan  1 test in 1 file · profile default

✓ sample.cel#twoNamedUsers                                        8ms

```

### Compare fields with each other

CEL can relate values that a matcher checks one at a time.

```yaml title="services/sample/cel.test.yaml"
tests:
  - id: totalAddsUp
    name: Total is the sum of item prices
    call: sample#echoOrder
    expect:
      cel:
        total matches items: response.body.body.items.map(i, i.price).sum() == response.body.body.total
```

```console
$ vc run sample.cel#totalAddsUp
plan  1 test in 1 file · profile default

✓ sample.cel#totalAddsUp                                          4ms

```

### Write response.body, not body

`vc check` knows every root and offers a fix.

```yaml title="services/sample/celerrors.test.yaml"
tests:
  - id: bareBody
    name: Bare body
    call: sample#listUsers
    expect:
      cel:
        twoUsers: size(body) == 2
```

```console
$ vc check
error[V2105]: `body` is not a root; did you mean `response.body`?
 --> services/sample/celerrors.test.yaml:7:24
  |
7 |         twoUsers: size(body) == 2
  |                        ^^^^
  = help: write `response.body`
  = fix: Write response.body (certain)

```

## How it behaves

- Each expression must evaluate to `true`. Anything else fails with V5102.
- Roots are the same as in templates: `response`, `var` and the others available at that spot. A bare `body` is not a root.
- Useful functions: `size`, `all`, `exists`, `map`, `filter`, `sum`, `has`, `matches`, `timestamp`, `duration`.
- `vc check` parses every expression and checks each root before the run.
- CEL checks are never replaced by merging; each level adds its own. See [merging](/vc-rs/reference/matchers/merging/).

## Common errors

- [V2105](/vc-rs/reference/diagnostics/v2105/): the expression reads a root that does not exist there, such as `body`.
- [V2305](/vc-rs/reference/diagnostics/v2305/): the expression does not parse.
- [V5102](/vc-rs/reference/diagnostics/v5102/): the expression evaluated to something other than `true`.
