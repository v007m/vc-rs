`every` passes when each element of a list matches the nested matcher.

```yaml
expect:
  body:
    match:
      body.items[*].price: {every: {gt: 0}}
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `every` | matcher or value | — | yes | A plain value means each element equals it. |

## Examples

The examples call `sample#echoOrder`, which posts a sample order to the demo service; the demo sends it back under `body`. See [Following along](/vc-rs/reference/matchers/#following-along).

### Every price is positive

A `[*]` path, such as `body.items[*].price`, collects one field from every element into a list. Use it to apply a matcher to one field of each element.

```yaml title="services/sample/every.test.yaml"
tests:
  - id: pricesPositive
    name: Every price is positive
    call: sample#echoOrder
    expect:
      body:
        match:
          body.items[*].price: {every: {gt: 0}}
```

### Use a list path for fields

Inside `every`, the matcher applies to the element itself. A map whose keys are not matcher names is a literal object, so this compares each item to the object `{price: {gt: 0}}`.

```yaml title="services/sample/every.test.yaml"
tests:
  - id: failsOnFieldMap
    name: Every item has a positive price
    call: sample#echoOrder
    expect:
      body:
        match:
          body.items: {every: {price: {gt: 0}}}
```

```console
$ vc run sample.every#failsOnFieldMap
plan  1 test in 1 file · profile default

✕ sample.every#failsOnFieldMap                                    5ms
```

## How it behaves

- The value must be a list. Anything else, including a missing value, fails.
- An empty list passes.
- A scalar matcher written straight on a `[*]` path, such as `body.items[*].price: {gt: 0}`, compares the whole list and fails. Wrap it in `every`, `some` or `none`.
- To check fields of each element, put the field in the path with `[*]`.

## Common errors

- [V1004](/vc-rs/reference/diagnostics/v1004/): a misspelled matcher next to a real one, such as `{gt: 1, gtt: 2}`. The help line suggests the closest name. A misspelled name on its own is not flagged: the map is compared as a literal value instead.
- [V5101](/vc-rs/reference/diagnostics/v5101/): the check did not hold for the response. The report shows the expected and the actual value.
