`size` checks the size of the response body. Write sizes with a unit.

```yaml
expect:
  size: {lt: 100kb}
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `size` | matcher with sizes | — | no | Units: `b`, `kb` (1024 bytes), `mb` (1024 kb), `gb` (1024 mb). Lowercase. |

## Examples

The examples call `sample#listUsers` on the demo service, which answers `[{"id":"1","name":"Ada Lovelace"},{"id":"2","name":"Grace Hopper"}]`. See [Following along](/vc-rs/reference/matchers/#following-along).

### Keep a response small



```yaml title="services/sample/size.test.yaml"
tests:
  - id: smallList
    name: The list is under 1 KiB
    call: sample#listUsers
    expect:
      size: {lt: 1kb}
```

```console
$ vc run sample.size#smallList
```

### A range



```yaml title="services/sample/size.test.yaml"
tests:
  - id: notEmptyNotHuge
    name: The list is between 10 bytes and 2 MiB
    call: sample#listUsers
    expect:
      size: {between: [10b, 2mb]}
```


### A size needs a unit

A bare number or an uppercase unit is rejected by `vc check`.

```yaml wrong title="services/sample/sizeerrors.test.yaml"
tests:
  - id: noUnit
    name: No unit
    call: sample#listUsers
    expect:
      size: {lt: 2KB}
```

```console
$ vc check
error[V2301]: invalid size `2KB`
 --> services/sample/sizeerrors.test.yaml:6:18
  |
6 |       size: {lt: 2KB}
  |                  ^^^
  = help: write a whole number and a unit: `512b`, `4kb`, `1mb` or `2gb`

1 error · 0 warnings · 41 files checked
```

## How it behaves

- The size is the number of bytes in the body.
- `kb`, `mb` and `gb` are powers of 1024.
- Write a whole number and a lowercase unit: `512b`, `4kb`, `1mb`, `2gb`.
- Any ordered matcher works: `gt`, `gte`, `lt`, `lte`, `between`.

## Common errors

- [V2301](/vc-rs/reference/diagnostics/v2301/): the size has no unit, or the unit is not one of `b`, `kb`, `mb`, `gb`.
- [V5101](/vc-rs/reference/diagnostics/v5101/): the check did not hold for the response. The report shows the expected and the actual value.
