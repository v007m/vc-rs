`length` passes when the number of characters, items or keys equals the argument, or matches a nested matcher.

```yaml
expect:
  body:
    match:
      body.tags: {length: 2}
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `length` | whole number or matcher | — | yes | Counts characters in a string, items in a list, keys in an object. |

## Examples

The examples call `sample#echoOrder`, which posts a sample order to the demo service; the demo sends it back under `body`. See [Following along](/vc-rs/reference/matchers/#following-along).

### An exact count



```yaml title="services/sample/length.test.yaml"
tests:
  - id: twoTags
    name: Two tags
    call: sample#echoOrder
    expect:
      body:
        match:
          body.tags: {length: 2}
```

### A range of lengths

Pass a matcher instead of a number.

```yaml title="services/sample/length.test.yaml"
tests:
  - id: idLongEnough
    name: ID has at least 5 characters
    call: sample#echoOrder
    expect:
      body:
        match:
          body.id: {length: {gte: 5}}
```


### Count keys and list paths

An object's length is its number of keys. A `[*]` path makes a list, so `length` counts its items.

```yaml title="services/sample/length.test.yaml"
tests:
  - id: counts
    name: Counts
    call: sample#echoOrder
    expect:
      body:
        match:
          body.items[0]: {length: 2}
          body.items[*].sku: {length: 2}
```

```console
$ vc run sample.length#counts

```

## How it behaves

- Strings count characters, lists count items, objects count keys.
- A missing value, a number or `null` fails.
- With a nested matcher, the length is checked with that matcher, such as `{length: {between: [1, 10]}}`.

## Common errors

- [V2306](/vc-rs/reference/diagnostics/v2306/): the argument is not a whole number or a matcher: `length takes a whole number or a matcher`.
- [V5101](/vc-rs/reference/diagnostics/v5101/): the check did not hold for the response. The report shows the expected and the actual value.
