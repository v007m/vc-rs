`none` passes when no element of a list matches the nested matcher.

```yaml
expect:
  body:
    match:
      body.items[*].sku: {none: {eq: C3}}
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `none` | matcher or value | — | yes | A plain value means no element equals it. |

## The API

The examples call `sample#echoOrder`. It posts a sample order to the demo's `/echo`, and the demo sends the request back, so the order shows up under `body`. Here are the fields these examples check; [Following along](/vc-rs/reference/matchers/#following-along) has the whole entry and how to start the demo.

```yaml title="services/sample/sample.api.yaml (excerpt)"
  - id: echoOrder
    name: Echo a sample order
    method: POST
    path: /echo
    body:
      tags: [new, vip]
      items:
        - {sku: A1, price: 10}
        - {sku: B2, price: 32.5}
      ...
```

```console
$ vc call sample#echoOrder

```

## Examples

### No item is C3

A `[*]` path, such as `body.items[*].price`, collects one field from every element into a list. Use it to apply a matcher to one field of each element.

```yaml title="services/sample/none.test.yaml"
tests:
  - id: noC3
    name: No SKU is C3
    call: sample#echoOrder
    expect:
      body:
        match:
          body.items[*].sku: {none: {eq: C3}}
```

### A missing list fails

Unlike [not](/vc-rs/reference/matchers/not/), `none` needs a list to be there.

```yaml title="services/sample/none.test.yaml"
tests:
  - id: failsOnMissing
    name: No coupon is expired
    call: sample#echoOrder
    expect:
      body:
        match:
          body.coupons: {none: {eq: expired}}
```

## How it behaves

- The value must be a list. Anything else, including a missing value, fails.
- An empty list passes.

## Common errors

- [V1004](/vc-rs/reference/diagnostics/v1004/): a misspelled matcher next to a real one, such as `{gt: 1, gtt: 2}`. The help line suggests the closest name.
- [V3208](/vc-rs/reference/diagnostics/v3208/): a warning for a misspelled matcher on its own when its name has five or more letters, such as `{startWith: A}`. It is still compared as a literal object; fix the name, or put the object under `eq:` to keep it.
- [V5101](/vc-rs/reference/diagnostics/v5101/): the check did not hold for the response. The report shows the expected and the actual value.
