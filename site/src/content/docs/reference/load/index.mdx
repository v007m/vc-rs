A `*.load.yaml` file reuses tests you already have as a traffic mix; it adds no requests or checks of its own.

```yaml title="load/sample/smoke.load.yaml"
name: Sample smoke load
mix:
  - test: sample.basics#listsUsers
    weight: 3
  - test: sample.basics#getsCreatedUser
    weight: 1
    thresholds:
      p95:
        lt: 300ms
stages:
  - duration: 5s
    users: 5
  - duration: 5s
    users: 0
thinkTime:
  min: 50ms
  max: 200ms
thresholds:
  p99:
    lt: 500ms
```

## Syntax

| Key | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| [`id`](/vc-rs/reference/load/id/) | file ID | from the path | no | `load/sample/smoke.load.yaml` is `sample.smoke`. |
| [`name`](/vc-rs/reference/load/name/) | text | — | no | Free text for people. |
| [`mix`](/vc-rs/reference/load/mix/) | list of `test`, `weight`, `thresholds` | — | yes | The tests and their relative shares. |
| [`stages`](/vc-rs/reference/load/stages/) | list of `duration`, `users` | — | yes | Users ramp from the previous stage's count. |
| [`thinkTime`](/vc-rs/reference/load/thinktime/) | duration, or `min` and `max` | `0s` | no | Pause after each iteration. |
| [`checks`](/vc-rs/reference/load/checks/) | `api` or `full` | `api` | no | `full` also runs each test's own `expect`. |
| [`thresholds`](/vc-rs/reference/load/thresholds/) | metric → matcher | — | no | `p50`, `p90`, `p95`, `p99`, `max`, `errorRate`, `rps`. |
| [`abortOn`](/vc-rs/reference/load/abort-on/) | list of metrics | `[]` | no | Stop early when one of these thresholds is breached. |

## How it behaves

- Load files live under `load/`, and their file IDs share one namespace with test files. A load file and a test file with the same ID are [V2001](/vc-rs/reference/diagnostics/v2001/).
- `vc check` checks load files like any other file: unknown tests, bad durations and rates, unknown keys.
- One iteration is one run of one mix test, picked by weight. Each iteration is one sample for the [metrics](/vc-rs/reference/load/metrics/).
- The exit code is 3 when a threshold is breached. See [`vc load`](/vc-rs/reference/load/vc-load/).
