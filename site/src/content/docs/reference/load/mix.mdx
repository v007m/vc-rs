`mix` lists existing tests by full ID; each user picks the next test by weight.

```yaml
mix:
  - test: sample.basics#listsUsers
    weight: 3                       # 3 of every 4 iterations
  - test: sample.basics#getsCreatedUser
    weight: 1                       # 1 of every 4
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `mix` | list | — | yes | At least one entry with a weight above 0. |
| `test` | full test ID, `<fileId>#<id>` | — | yes | Must name an existing test ([V2003](/vc-rs/reference/diagnostics/v2003/)). |
| `weight` | whole number | — | yes | Relative share. Weights don't need to add up to anything. |
| `thresholds` | metric → matcher | — | no | Like the scenario's [`thresholds`](/vc-rs/reference/load/thresholds/), but measured on this test's iterations only. |

## Examples

### Weighted mix

```yaml title="load/sample/smoke.load.yaml (excerpt)"
mix:
  - test: sample.basics#listsUsers
    weight: 3
  - test: sample.basics#getsCreatedUser
    weight: 1
    thresholds:
      p95:
        lt: 300ms
```

```console
$ vc load sample.smoke
...
sample.smoke — Sample smoke load · finished after 10 s · 198 iterations · 19.8 rps · 0 errors
latency p50 3.4 ms · p90 5.6 ms · p95 7.1 ms · p99 8.9 ms · max 9.8 ms
```

### A threshold on one test

A mix entry's thresholds name the test when they are breached:

```yaml title="load/sample/strict.load.yaml (excerpt)"
mix:
  - test: sample.basics#listsUsers
    weight: 3
  - test: sample.basics#getsCreatedUser
    weight: 1
    thresholds:
      p95:
        lt: 2ms
```

```console
$ vc load sample.strict
...
breached sample.basics#getsCreatedUser: p95 at 11.215 ms (lt 2 ms)
```

### A test that doesn't exist

```console
$ vc check
error[V2003]: unknown test "sample.basics#listUser"
 --> load/bad/one.load.yaml:3:11
  |
3 |   - test: sample.basics#listUser
  |           ^^^^^^^^^^^^^^^^^^^^^^ no test has this ID
  = help: did you mean one of `sample.basics#listsUsers`, `sample.basics#createsUser`?
```

## How it behaves

- An iteration runs the whole test: its `before` actions and its call or steps. See [Lifecycle in load runs](/vc-rs/reference/load/lifecycle/).
- By default only the apis' own `expect` decides whether an iteration failed. Set [`checks: full`](/vc-rs/reference/load/checks/) to use each test's `expect` too.

<Aside type="caution">
A mix whose weights are all `0` passes `vc check`, but `vc load` stops with `error: the mix has no test with a weight above 0` and exits 2. Give at least one test a weight of 1 or more.
</Aside>
