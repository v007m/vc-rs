`name` is free text that says what a scenario is for.

```yaml title="load/sample/smoke.load.yaml (excerpt)"
name: Sample smoke load
```

## Syntax

| Field | Type | Default | Required | Notes |
| --- | --- | --- | --- | --- |
| `name` | text | — | no | Any text, spaces and punctuation included. |

## Examples

```yaml title="load/checkout/peak.load.yaml (excerpt)"
name: Black Friday checkout mix
```

```yaml title="load/sample/strict.load.yaml (excerpt)"
name: Too strict on purpose
```

## How it behaves

- `vc load` is always called with the scenario's [ID](/vc-rs/reference/load/id/), never its name. The terminal summary starts with the ID, then the name when the scenario has one (`sample.smoke — Sample smoke load · finished after 10 s …`).
- `vc load --json` gives the name as `name`, or `null` when the scenario has none.
