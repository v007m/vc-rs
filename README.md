# Vibranium v2

A git-native API testing engine: functional, contract and load tests of HTTP APIs, written as YAML and run from a CLI, TUI, MCP server or web UI. It is a ground-up rewrite of [Vibranium v1](https://github.com/sarathm09/vibranium).

**Status:** design complete; implementation starting at milestone M0. See [`docs/design/HANDOVER.md`](docs/design/HANDOVER.md).
