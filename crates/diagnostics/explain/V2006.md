# V2006: Reserved ID

The ID is a name Vibranium reserves for a template root: `var`, `env`, `secret`, `response`, `request`, `example`,
`item`, `iteration`, `fake`, `dataset` or `run`. An action named `response` would make `${response.body}` ambiguous, so
choose another ID.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: request
    path: /users/1
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```
