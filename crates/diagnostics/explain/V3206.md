# V3206: A test-level default that no step uses

A test-level default (`auth`, `headers`, `query`, `body`, `poll` or `expect`) is set, but every step sets its own, so the
default is never used. Remove it, or remove the steps' own values so that the default applies.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: createsTwice
    headers: {x-trace: '1'}
    steps:
      - call: users#createUser
        headers: {x-trace: '2'}
      - call: users#createUser
        headers: {x-trace: '3'}
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: createsTwice
    headers: {x-trace: '1'}
    steps:
      - call: users#createUser
      - call: users#createUser
```
