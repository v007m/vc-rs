# V1005: Required key missing

A key this place needs is missing: every api needs a `path`, every test an `id`, and a `poll` needs `until`, `every` and
`timeout`. Nothing is filled in for a required key, so add it.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    method: GET
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    method: GET
    path: /users/1
```
