# V5111: Template failed to render at run time

A template could not be rendered when the action ran: a path is missing from the value it walks, or a pipe got a
value of the wrong type. The report shows the path and the value it was walking. Here the service answers
`{"id": 7, "name": "Ada"}`, with no `data` wrapper.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: Ada
    save:
      userId: ${response.body.data.id}
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: Ada
    save:
      userId: ${response.body.id}
```
