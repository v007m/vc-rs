# V1009: Map key is not text

A map key is a list or a map (YAML's `? ` complex key). Keys are always plain text; write each part as its own key.

## Wrong

```yaml
# file: services/users/users.api.yaml
vars:
  ? [region, zone]
  : eu-west-1a
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
vars:
  region: eu-west
  zone: eu-west-1a
apis: []
```
