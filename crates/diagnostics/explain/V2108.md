# V2108: GraphQL variable missing from `variables`

An operation declares its variables, such as `query GetProduct($id: ID!)`. A variable whose type ends in `!` and that
has no default must get a value, so `body.variables` must give it one; the server refuses the request otherwise. Give
it a value, or a default in the document (`$limit: Int! = 10`). `variables` written as one template, such as
`${var.filters}`, is not checked, since its keys are known only when the test runs. A value for a variable the
operation does not declare is V2109.

## Wrong

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
apis:
  - id: getProduct
    body:
      query: 'query GetProduct($id: ID!) { product(id: $id) { id name } }'
```

## Right

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
apis:
  - id: getProduct
    body:
      query: 'query GetProduct($id: ID!) { product(id: $id) { id name } }'
      variables: {id: p1}
```
