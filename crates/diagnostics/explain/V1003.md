# V1003: `syntaxVersion` newer than this Vibranium, or missing

`vibranium.config.yaml` must say which version of the syntax it is written in, with `syntaxVersion`. A version newer than
this Vibranium reads is refused rather than half understood; upgrade `vc` instead. The first version is 2, so `0` or `1`
is refused too; a Vibranium v1 project is converted with `vc migrate v1 <folder>`.

## Wrong

```yaml
# file: vibranium.config.yaml
syntaxVersion: 3
project: shop
profiles:
  - id: dev
    default: true
```

## Right

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
```
