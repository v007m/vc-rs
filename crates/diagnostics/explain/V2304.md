# V2304: Pipe or path cannot apply to that value's type

A pipe or path is applied to a value of a type it cannot handle, such as `upper` on a number. It is checked where the
value's type is known: a var every profile sets to a literal of one type.

## Wrong

```yaml
# file: services/users/users.api.yaml
vars:
  limit: 10
  region: eu
apis:
  - id: listUsers
    path: /users
    query:
      limit: ${var.limit | upper}
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: listsUsers
    call: users#listUsers
```

## Right

```yaml
# file: services/users/users.api.yaml
vars:
  limit: 10
  region: eu
apis:
  - id: listUsers
    path: /users
    query:
      region: ${var.region | upper}
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: listsUsers
    call: users#listUsers
```
