# V1006: Duplicate key in a map

A map has the same key twice. YAML would keep only one of the values without a word, so Vibranium refuses the file and
points at both. Keep one of them.

## Wrong

```yaml
# file: services/users/users.api.yaml
name: Users
name: People
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
name: Users
apis: []
```
