# V5101: Expectation failed

A check in `expect` did not hold for the response: a status, header, body match, schema or timing. The report shows
the expected and the actual value side by side. Here the service answers `201 Created`, but the test expects `200`; a
test's `status` replaces the api's.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: Ada
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: createsUser
    call: users#createUser
    expect:
      status: 200
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: Ada
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: createsUser
    call: users#createUser
    expect:
      status: 201
```
