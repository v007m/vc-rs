# V2109: Variable the operation does not declare

`body.variables` gives a value for a variable the operation does not declare. A GraphQL server ignores it, so the
request still runs, but the value never reaches the operation; most often the name is misspelt, and the fix is the
declared name when one is close. Declare the variable in the operation (`query GetProduct($id: ID!, $locale: String)`)
if the operation should use it, or remove the value. A missing value for a variable the operation needs is V2108.

## Wrong

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
apis:
  - id: getProduct
    body:
      query: 'query GetProduct($id: ID!, $locale: String) { product(id: $id, locale: $locale) { id name } }'
      variables: {id: p1, locle: en}
```

## Right

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
apis:
  - id: getProduct
    body:
      query: 'query GetProduct($id: ID!, $locale: String) { product(id: $id, locale: $locale) { id name } }'
      variables: {id: p1, locale: en}
```
