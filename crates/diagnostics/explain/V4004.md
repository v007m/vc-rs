# V4004: Tag, profile or dataset name breaks the convention

Tags are lowercase, kebab-case for two words (`smoke`, `slow-network`); profiles are lowercase single words (`dev`,
`staging`); a dataset's ID is its file stem in camelCase. `vc check --fix` renames it and updates every reference.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    tags: [Smoke, slow_network]
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    tags: [smoke, slow-network]
```
