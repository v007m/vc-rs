# V1001: File is not valid YAML or JSON, or its suffix is not a known kind

The file could not be read as YAML (or as JSON, for a `.json` definition file), so nothing else in it is checked until it
parses. The usual causes are a quote or bracket left open, or a tab used for indentation. A definition file must also end
in a suffix Vibranium knows, such as `.api.yaml` or `.test.yaml`.

## Wrong

```yaml
# file: services/users/users.api.yaml
name: "Users
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
name: "Users"
apis: []
```
