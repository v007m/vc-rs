# V3102: More than one default profile

More than one profile is marked `default: true`, so it is unclear which one a run uses when it names none. Keep the mark
on one profile.

## Wrong

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
  - id: ci
    default: true
```

## Right

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
  - id: ci
```
