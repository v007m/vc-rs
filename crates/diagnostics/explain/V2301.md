# V2301: Invalid duration or size

A duration or size is not written in a form Vibranium reads. Units are always written out: durations as `250ms`, `2s`
or `1m`, sizes as `4kb` or `1mb`. A bare number is never milliseconds.

A duration or size key also takes no template (`timeout: ${var.t}`): write the value out. To change the default timeout
per run, use `--set defaults.timeout=10s` or `VIB_DEFAULTS_TIMEOUT`. Only a flow auth's `expiresIn` is rendered from a
template.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    timeout: soon
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    timeout: 5s
```
