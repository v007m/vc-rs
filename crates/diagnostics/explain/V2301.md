# V2301: Invalid duration or size

A duration or size is not written in a form Vibranium reads. Units are always written out: durations as `250ms`, `2s`
or `1m`, sizes as `4kb` or `1mb`. A bare number is never milliseconds.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    timeout: soon
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    timeout: 5s
```
