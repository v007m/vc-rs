# V3104: Skip expired; the test runs again

A `skip` has an `until` date that has passed (dates are compared in UTC), so the skip is ignored and the test runs again.
This warning makes sure a forgotten skip is noticed; the fix removes the skip, or move `until` later if the reason
still holds. `vc skip --until` refuses such a date with this code, so it is never written.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    skip:
      reason: flaky upstream, see issue 212
      until: 2026-01-31
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
```
