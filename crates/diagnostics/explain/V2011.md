# V2011: A client certificate, key or trusted root file cannot be read

`vc check` reads the `http.tls` files the config names as text: each `ca` root, and the `cert`, `key` or `pkcs12`
of every `clients` entry, whatever its `profiles`. A file that is missing, cannot be opened, is not a regular file
(a FIFO, a device, a folder) or is over 1 MiB is this error, which a run would stop on (V5125). A relative path is
read from the project root. When the file is missing and one name in its folder is close, the fix is to use it. A
value with a `${…}` is left to the run, which renders it first.

## Wrong

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
http:
  tls:
    clients:
      - id: paymentsClient
        hosts: [payments.internal.example]
        cert: certs/payments-client.pem
        key: certs/payments-clinet.key
```

## Right

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
http:
  tls:
    clients:
      - id: paymentsClient
        hosts: [payments.internal.example]
        cert: certs/payments-client.pem
        key: certs/payments-client.key
```
