# V2308: Unknown pipe or wrong pipe arguments

A template names a pipe that does not exist, or passes it the wrong arguments. The diagnostic suggests the closest pipe
name; the syntax reference lists every pipe with its arguments.

## Wrong

```yaml
# file: services/users/users.api.yaml
vars:
  host: ' api.example.com '
baseUrl: https://${var.host | trimm}
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
vars:
  host: ' api.example.com '
baseUrl: https://${var.host | trim}
apis: []
```
