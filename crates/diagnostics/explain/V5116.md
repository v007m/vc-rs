# V5116: Hook ran past its time or memory budget

A hook ran past its time or memory budget and was stopped. The message says which budget it overran and the
TypeScript line it was on, and the action it belongs to fails. Hooks run inside the engine with every other hook of
the run, so a loop that never ends or an array that only grows is stopped rather than left to hold up the run. Bound
the work by the input it is given.

## Wrong

```yaml
# file: services/orders/orders.test.yaml
tests:
  - id: listsOrders
    call: orders#listOrders
    expect:
      custom:
        - function: ../../hooks/checks.ts#hasOrders
```

```ts
# file: hooks/checks.ts
export function hasOrders({ response }: { response: { body: unknown[] } }): boolean {
  let i = 0;
  while (response.body[i] !== undefined || i >= 0) {
    i++;
  }
  return i > 0;
}
```

## Right

```yaml
# file: services/orders/orders.test.yaml
tests:
  - id: listsOrders
    call: orders#listOrders
    expect:
      custom:
        - function: ../../hooks/checks.ts#hasOrders
```

```ts
# file: hooks/checks.ts
export function hasOrders({ response }: { response: { body: unknown[] } }): boolean {
  return response.body.length > 0;
}
```
