# V2004: `$file`, spec or snapshot reference not found

A `$file` names a file that is not in the project. The path is relative to the file that holds the `$file`, and a
`#/pointer` after it points inside the file. When exactly one file has a close name, the fix rewrites the path.

An api file's `source.openapi` that is a path, not a URL, must name a file in the project too. That path is relative
to the project root.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      $file: data/usr.json
```

```json
# file: services/users/data/user.json
{"name": "Ann"}
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      $file: data/user.json
```

```json
# file: services/users/data/user.json
{"name": "Ann"}
```
