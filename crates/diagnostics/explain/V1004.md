# V1004: Unknown key

The key is not one this place accepts. It is usually a typo, and the diagnostic suggests the closest key with a certain
fix. Keys are checked so that a misspelt setting is reported instead of silently ignored. A matcher map is checked the
same way: a key that is not a matcher's name, next to one that is (`{gt: 0, lenght: 3}`), is V1004, and so is any key
that is not a matcher's name in a status map or `saveOn`, which are never literal objects. Elsewhere a map with no
matcher's name as a key is a literal object; when its one key is close to a matcher's name, that is the warning V3207.

## Wrong

```yaml
# file: services/users/users.api.yaml
nmae: Users
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
name: Users
apis: []
```
