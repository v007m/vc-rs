# V1004: Unknown key

The key is not one this place accepts. It is usually a typo, and the diagnostic suggests the closest key with a certain
fix. Keys are checked so that a misspelt setting is reported instead of silently ignored.

## Wrong

```yaml
# file: services/users/users.api.yaml
nmae: Users
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
name: Users
apis: []
```
