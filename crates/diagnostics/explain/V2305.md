# V2305: Template or CEL does not parse

A template (`${...}`) or a CEL expression does not parse. The diagnostic points at the character where parsing stopped
and says what it expected there; usually a `}` or a quote is missing.

## Wrong

```yaml
# file: services/users/users.api.yaml
vars:
  host: api.example.com
baseUrl: https://${var.host
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
vars:
  host: api.example.com
baseUrl: https://${var.host}
apis: []
```
