# V2311: Redact pattern does not compile

A `redact.rules` entry with `regex` masks every match in the text a run stores. A run's redactor fails closed: when
the pattern does not compile, it cannot tell what to mask, so it masks every text, and reports and `history.db` show
only `••••`. `vc check` compiles each pattern the way a run does and reports the one that fails, with the reason. To
match a character that has a meaning in a regex, such as `[`, `(` or `.`, as itself, escape it with `\`.

## Wrong

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
redact:
  rules:
    - regex: "card-[0-9"
```

## Right

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
redact:
  rules:
    - regex: "card-[0-9]+"
```
