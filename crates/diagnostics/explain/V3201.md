# V3201: `PUT`, `PATCH` or `DELETE` uses a shared value from `beforeRun` or `beforeAll`

A `PUT`, `PATCH` or `DELETE` call changes a value that a `beforeRun` or `beforeAll` action shares with other tests. The
tests then depend on the order they run in; give the test its own data instead, made in its steps or in `beforeEach`.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml
# file: services/users/crud.test.yaml
beforeAll:
  - id: member
    call: users#createUser
tests:
  - id: renamesMember
    call: users#renameUser
    vars:
      userId: ${var.member.userId}
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: renamesMember
    steps:
      - call: users#createUser
      - call: users#renameUser
```
