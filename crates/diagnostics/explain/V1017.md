# V1017: Not a host pattern

Each `hosts` item of an `http.tls.clients` entry names the hosts its certificate is sent to: `host`, `host:port` or
`*.domain`, where `*` stands for exactly one leftmost label. A URL, a path, a user name or a `*` anywhere else can
never match a request's host, so the certificate would never be sent. When the item is a URL, the fix keeps only
its host and port.

## Wrong

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
http:
  tls:
    clients:
      - id: partnerClient
        hosts: ['https://api.partner.example/v1', 'api.*.example']
        cert: certs/partner.crt
        key: certs/partner.key
```

## Right

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
profiles:
  - id: dev
    default: true
http:
  tls:
    clients:
      - id: partnerClient
        hosts: [api.partner.example, '*.partner.example:8443']
        cert: certs/partner.crt
        key: certs/partner.key
```
