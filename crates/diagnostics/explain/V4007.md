# V4007: A value in a `path` ends in the `urlEncode` pipe, which a run applies already

A run percent-encodes each `${…}` value in an api's `path` as one segment, so `a/b c` is sent as `a%2Fb%20c`. A value
whose last pipe is `urlEncode` is already encoded, so the run sends it as the pipe left it rather than encoding it
twice. The pipe does nothing there. The certain fix removes it, together with its `|`. Pipes before it stay, and a
`urlEncode` followed by another pipe is not reported.

## Wrong

```yaml
# file: services/users/users.api.yaml
baseUrl: https://api.example.com
apis:
  - id: getUser
    path: /users/${var.userId | urlEncode}
    vars:
      userId: a b
```

## Right

```yaml
# file: services/users/users.api.yaml
baseUrl: https://api.example.com
apis:
  - id: getUser
    path: /users/${var.userId}
    vars:
      userId: a b
```
