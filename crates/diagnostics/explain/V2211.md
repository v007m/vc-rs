# V2211: A key that works only beside another one that is missing

A key is written, but it does something only when another key is there too, and that key is missing:

- `parallel` on an action without `repeat` or `forEach`. It sets how many iterations run at a time, and an action that
  does not loop has one.
- An `abortOn` metric that no `thresholds` entry names, in the scenario or in a mix test. A run stops early only when a
  threshold on the metric is breached, so the run would never stop for it.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: listUsers
    path: /users
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: listsUsers
    steps:
      - call: users#listUsers
        parallel: 5
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: listUsers
    path: /users
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: listsUsers
    steps:
      - call: users#listUsers
        repeat: 10
        parallel: 5
```
