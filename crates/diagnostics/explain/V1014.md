# V1014: GraphQL document does not parse

A `graphql` api's `body.query` is a GraphQL document: written inline, or in a `.graphql` or `.gql` file named by
`$file`. The document is parsed when the project is checked, so a syntax error, such as an unclosed brace or an
argument without a value, is reported before anything is sent. The diagnostic points at the spot where the parser
stopped: in the YAML for an inline document written as one line or as a `|` block, and in the file for a `$file`
document. Any other inline form is underlined as a whole.

## Wrong

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
apis:
  - id: getProduct
    body:
      query: |
        query GetProduct($id: ID!) {
          product(id: $id) { id name
        }
      variables: {id: p1}
```

## Right

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
apis:
  - id: getProduct
    body:
      query: |
        query GetProduct($id: ID!) {
          product(id: $id) { id name }
        }
      variables: {id: p1}
```
