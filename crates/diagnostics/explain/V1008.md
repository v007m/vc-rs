# V1008: YAML tag not supported

YAML tags such as `!!str` or `!include` are not supported. Every value's type comes from the key it sits under, so a tag
is never needed; quote a value to keep it as text.

## Wrong

```yaml
# file: services/users/users.api.yaml
name: !!str Users
apis: []
```

## Right

```yaml
# file: services/users/users.api.yaml
name: Users
apis: []
```
