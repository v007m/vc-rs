# V2302: Wrong value type

A value has the wrong type for its key: text where a number is expected, a map where a list is expected, a date that is
not `YYYY-MM-DD`. Quoting a number makes it text, so `'2'` is not the integer `2`.

An `$extend` base must be a template that renders an object, such as `${original.body}`; a number, plain text, a
list or a map written in place can never be one.

`reports.formats` takes `ctrf`, `junit`, `html` and the IDs of reporter plugins. `vc check` reads each installed
plugin's manifest, so it also reports an auth, importer or executor plugin listed there: only a reporter writes a
report.

## Wrong

```yaml
# file: vibranium.config.yaml
syntaxVersion: '2'
project: shop
profiles:
  - id: dev
    default: true
```

## Right

```yaml
# file: vibranium.config.yaml
syntaxVersion: 2
project: shop
profiles:
  - id: dev
    default: true
```
