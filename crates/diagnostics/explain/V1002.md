# V1002: YAML structure error (indentation, a mapping expected)

The YAML is well formed text, but its indentation does not build the structure it seems to: a key is indented less or more
than its siblings, or a list item and a map key are mixed at one level. Keys of one map line up exactly.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
   path: /users/1
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```
