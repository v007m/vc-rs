# V2306: Matcher argument invalid

A matcher's argument is not one it accepts: an unknown `type`, a `regex` that does not compile, or a `between` without
exactly two values. The diagnostic says what the matcher needs.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    expect:
      body:
        match:
          id: {type: strng}
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    expect:
      body:
        match:
          id: {type: string}
```
