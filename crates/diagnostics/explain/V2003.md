# V2003: Unknown api or test

A `call`, `test` or `cleanup.call` names an api or test that does not exist. Another file's items are referred to by
their full ID, `fileId#id`; the diagnostic suggests the closest ID of the right kind, same-file IDs first. The items of the file the
reference names are compared first; when none is close, an item of that name in another file is offered.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUsr
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
```
