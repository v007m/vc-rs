# V4006: A `path` holds a `{name}` placeholder

An api's `path` is a template, so a path parameter is written as a var: `/poll/${var.jobId}`. The OpenAPI style
`/poll/{jobId}` is not a template; the request is sent with the text `{jobId}` in its URL. Write each placeholder as
`${var.name}` and set the var where the test or the api can see it. The suggested fix rewrites each one. Braces around
anything but a name (`{ x }`, `{1}`) and `${…}` templates are left alone.

## Wrong

```yaml
# file: services/jobs/jobs.api.yaml
baseUrl: https://api.example.com
apis:
  - id: getJob
    path: /poll/{jobId}
```

## Right

```yaml
# file: services/jobs/jobs.api.yaml
baseUrl: https://api.example.com
apis:
  - id: getJob
    path: /poll/${var.jobId}
    vars:
      jobId: j-1
```
