# V2205: Cycle through `test:` reuse

Tests reuse each other through `test:` steps, and here the reuse goes round in a circle, so running any of them would
never end. The diagnostic shows the whole chain; break it by removing one `test:` step.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: signsUp
    steps:
      - test: logsIn
  - id: logsIn
    steps:
      - call: users#getUser
      - test: signsUp
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: signsUp
    steps:
      - test: logsIn
  - id: logsIn
    steps:
      - call: users#getUser
```
