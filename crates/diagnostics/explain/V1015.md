# V1015: GraphQL schema file is neither SDL nor an introspection result

A `type: graphql` api file's `graphql.schema` names the schema its documents are checked against: an SDL file
(`.graphql` or `.graphqls`) that holds only type definitions, or a `.json` file that holds the answer to an
introspection query, `{"data": {"__schema": …}}` or `{"__schema": …}`. V1015 is a file that reads but is not a
schema: SDL that holds an operation or a fragment, or JSON without `__schema`, without its `types` list, or with a
type that is not what an introspection result holds there. The diagnostic points at the definition or the JSON value
that is wrong. A syntax error in an SDL file is V1014, as in any GraphQL file.

## Wrong

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
graphql:
  schema: {$file: schema.json}
apis:
  - id: getProduct
    body:
      query: "query GetProduct($id: ID!) { product(id: $id) { id name } }"
      variables: {id: p1}
```

```json
# file: services/catalog/schema.json
{"openapi": "3.1.0", "paths": {}}
```

## Right

```yaml
# file: services/catalog/catalog.api.yaml
type: graphql
graphql:
  schema: {$file: schema.graphql}
apis:
  - id: getProduct
    body:
      query: "query GetProduct($id: ID!) { product(id: $id) { id name } }"
      variables: {id: p1}
```

```graphql
# file: services/catalog/schema.graphql
type Query {
  product(id: ID!): Product
}

type Product {
  id: ID!
  name: String
}
```
