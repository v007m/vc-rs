# V3203: Call to a `deprecated` api

A test calls an api marked `deprecated: true`. The call still runs; the warning is a reminder to move to the api that
replaces it before the old one is removed.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: listLegacyUsers
    path: /legacy/users
    deprecated: true
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#listLegacyUsers
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: listLegacyUsers
    path: /legacy/users
    deprecated: true
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
```
