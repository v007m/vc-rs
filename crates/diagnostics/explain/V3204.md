# V3204: Unquoted value that YAML cut at `  # ` (a comment)

YAML reads a ` #` in an unquoted value as the start of a comment, so the value was cut short: `see #212` keeps only
`see`. Quote the value to keep the `#` and what follows it.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    skip: flaky upstream, see #212
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    skip: 'flaky upstream, see #212'
```
