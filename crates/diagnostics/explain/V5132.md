# V5132: A client's report folder is not inside the project

A run started from the web UI, or any client of `vc serve`, may name the folder its report files go in (`out` in the
`Run` request, as `--out` is for `vc run`). That folder is a path inside the project: relative to the project root,
with no `..`, and inside the project on disk, links followed. An absolute path, a `..` part, or a folder that leads
outside through a link is refused before the run starts, and nothing runs. A folder outside the project is yours to
choose at the command line with `vc run --out <dir>`, which is not checked (D327, D671).

## Wrong

The request names a folder above the project.

```json
{"out": "../shared/reports"}
```

## Right

```json
{"out": "reports/ci"}
```
