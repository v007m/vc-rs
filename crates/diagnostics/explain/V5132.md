# V5132: A client's report folder is not inside the project

A run started from the web UI, or any client of `vc ui`'s server, may name the folder its report files go in: `out` in the
`Run` request, as `--out` is for `vc run`, or `reports.dir` in a request's `sets`. That folder is a path inside the
project: relative to the project root, with no `..`, and inside the project on disk, links followed. An absolute path,
a `..` part, or a folder that leads outside through a link is refused before the run starts, and nothing runs. A folder
outside the project is yours to choose at the command line with `vc run --out <dir>`, or with
`vc ui --set reports.dir=<dir>` for every run the server starts, which are not checked (D327, D671, D685). The same
check applies to a `reports.dir` the web UI writes into your user config; edit that file yourself for a folder
outside the project (D712).

## Wrong

The request names a folder above the project, as `out` or as a set.

```json
{"out": "../shared/reports", "sets": ["reports.dir=/var/reports"]}
```

## Right

```json
{"out": "reports/ci", "sets": ["reports.dir=reports/ci"]}
```
