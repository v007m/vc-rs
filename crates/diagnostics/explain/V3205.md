# V3205: A test-level `body` default reaches a GET or HEAD step

A test-level `body` is a default for every step, and here it reaches a `GET` or `HEAD` call that takes no body. Put the
`body` on the step that sends it instead.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: createsThenReads
    body: {name: Ada}
    steps:
      - call: users#createUser
      - call: users#getUser
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
  - id: createUser
    method: POST
    path: /users
    save:
      userId: ${response.body.id}
  - id: renameUser
    method: PUT
    path: /users/${var.userId}
    body:
      name: Bo
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: createsThenReads
    steps:
      - call: users#createUser
        body: {name: Ada}
      - call: users#getUser
```
