# V1010: More than one YAML document in a file

A file holds exactly one YAML document, and a `---` line starts a second. Put the second document's content in its own
file, or merge it into the first.

## Wrong

```yaml
# file: services/users/users.api.yaml
name: Users
---
name: People
```

## Right

```yaml
# file: services/users/users.api.yaml
name: Users
apis: []
```
