# V4003: File name or folder breaks the convention

Api files live at `services/<service>/<service>.api.yaml` and test files at `services/<service>/<area>.test.yaml`, so a
test file sits next to the apis it calls and its ID reads `<service>.<area>`. Vibranium finds a file wherever it is;
this warning only keeps projects alike. A test file named after its service (`services/users/users.test.yaml`, ID
`users.users`) is reported too: name it after the area its tests cover, such as `crud`. `vc rename` moves a file and updates every reference.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
```
