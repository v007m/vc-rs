# V5124: The response is not a GraphQL response

A call to a `graphql` api got a 2xx response whose body is not a GraphQL response: not a JSON object with `data` or
`errors`, or one whose `errors` is not a list. This usually means a wrong endpoint, such as a web page or a REST route
answering where the GraphQL server should be, so the step fails even without `expect.errors`. A response with a status
other than 2xx is left to the status check, since GraphQL servers answer 400 to a document they cannot run. Here
`graphql.path` points at the web app's home page instead of its `/graphql` endpoint.

## Wrong

```yaml
# file: services/accounts/accounts.api.yaml
type: graphql
graphql:
  path: /
apis:
  - id: getMe
    body:
      query: '{ me { id name } }'
```

## Right

```yaml
# file: services/accounts/accounts.api.yaml
type: graphql
graphql:
  path: /graphql
apis:
  - id: getMe
    body:
      query: '{ me { id name } }'
```
