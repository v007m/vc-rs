# V2303: Invalid status code or class

A status is neither a code from 100 to 599 nor a class such as `2xx`. Write the exact code, or the class to accept any
code in it.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    expect:
      status: 99x
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    expect:
      status: 2xx
```
