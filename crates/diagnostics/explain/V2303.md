# V2303: Invalid status code or class, or an empty status map or list

A status is neither a code from 100 to 599 nor a class such as `2xx`. Write the exact code, or the class to accept any
code in it. A status map or list with nothing in it (`status: {}`, `saveOn: []`) checks nothing, so it is V2303 too.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    expect:
      status: 99x
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/1
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    call: users#getUser
    expect:
      status: 2xx
```
