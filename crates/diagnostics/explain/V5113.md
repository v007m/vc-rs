# V5113: No cache key: the cross-run cache is off

A `cache:` action needs a key to seal its entries, from `VIB_CACHE_KEY` (64 hex digits) or the OS keychain. Neither
gave one, as in most CI, so the cache is off for this run and `cache:` actions run every time. It is a notice, not a
failure. The files stay as they are: set `VIB_CACHE_KEY` from the CI's secret store, or keep the warning where
caching does not matter. `--no-cache` turns the cache off on purpose and silences it.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: Admin
    save:
      userId: ${response.body.id}
```

```yaml
# file: services/users/admin.test.yaml
beforeAll:
  - id: admin
    call: users#createUser
    cache:
      for: 12h
tests:
  - id: createsUser
    call: users#createUser
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: Admin
    save:
      userId: ${response.body.id}
```
