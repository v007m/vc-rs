# V2103: Unknown example or dataset column

A `${example.x}` names a column that no row of the test's `examples` has. Only inline rows are checked; rows from a
`$file` or a dataset are known only when the test runs.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    examples:
      - userId: 1
      - userId: 2
    call: users#getUser
    vars:
      userId: ${example.usrId}
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: getUser
    path: /users/${var.userId}
```

```yaml
# file: services/users/crud.test.yaml
tests:
  - id: getsUser
    examples:
      - userId: 1
      - userId: 2
    call: users#getUser
    vars:
      userId: ${example.userId}
```
