# V5106: A lifecycle action this test needs failed

A `beforeRun`, `beforeAll`, `beforeEach` or `before` action the test depends on failed, so the test is blocked: it is
not run, and the report points at the action that failed. Fix that action first. Here `beforeAll` creates the user
with a body the service rejects, so no test in the file can run.

## Wrong

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: ${var.name}
    expect:
      status: 201
  - id: listUsers
    path: /users
```

```yaml
# file: services/users/crud.test.yaml
beforeAll:
  - call: users#createUser
    vars:
      name: ""
tests:
  - id: listsUsers
    call: users#listUsers
```

## Right

```yaml
# file: services/users/users.api.yaml
apis:
  - id: createUser
    method: POST
    path: /users
    body:
      name: ${var.name}
    expect:
      status: 201
  - id: listUsers
    path: /users
```

```yaml
# file: services/users/crud.test.yaml
beforeAll:
  - call: users#createUser
    vars:
      name: Ada Lovelace
tests:
  - id: listsUsers
    call: users#listUsers
```
