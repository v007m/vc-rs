~/shop ❯ vc explain V2205
V2205 error · cycle in reused tests
A step or lifecycle action written as test: <testId> runs that whole test inside this one: its before, steps and after.
If test A reuses B, and B reuses A (directly or through other tests), the run could never finish. vc check reports it,
vc run refuses to start, and nothing is sent. Lifecycle actions and steps that use call: are never part of a cycle.
✕ fails ✓ works break the loop where only data is needed
